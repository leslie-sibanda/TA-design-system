# Shared Agent Guidance

This directory is reserved for tool-neutral skills and workflows that can be used by different coding agents.

Canonical repository instructions live in `../AGENTS.md`. Agent-specific configuration should point back to those instructions and must not redefine architecture, security, or quality rules independently.

Planned skills:

- `plan-component` — turn a request into a scoped brief, contract, and implementation plan.
- `implement-component` — build a component from Base UI primitives and TeacherActive tokens.
- `document-component` — create usage guidance, examples, API notes, and registry metadata.
- `review-component` — review accessibility, API quality, theming, tests, and documentation.
- `release-registry` — validate package and registry outputs before release.
