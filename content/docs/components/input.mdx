**Design proposal · Not released**

## Overview

The canonical Input component and executable examples are not implemented yet.

## Usage guidance

Keep a persistent label. Placeholder text is an example, not a replacement for the field name. Use a textarea for longer responses and a select or combobox for constrained choices.

## States and accessibility

| State | Requirement |
| --- | --- |
| Default and focus | Keep keyboard focus visible without shifting the layout. |
| Error | Explain how to correct the value and associate the error with its field. |
| Disabled and read-only | Distinguish unavailable fields from values that cannot be edited. |

## Reference

Labels, descriptions, errors and supported native input attributes must be documented alongside the implemented API. Markdown export and installation guidance are pending.
