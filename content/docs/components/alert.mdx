**Design proposal · Not released**

## Overview

The canonical Alert component is not implemented yet.

## Usage guidance

Explain what happened, what it means and what to do next. Reserve assertive announcements for urgent dynamic messages. Static information should not interrupt a screen reader.

## States and accessibility

| State | Requirement |
| --- | --- |
| Information and success | Pair meaningful text with any colour or icon. |
| Warning and error | Describe the impact and how to recover. |
| Dismissible | Use a labelled control and predictable focus behaviour. |

## Reference

Semantic variants and announcement behaviour need a validated component contract. Shared status meaning must remain consistent across themes. Markdown export is pending.
