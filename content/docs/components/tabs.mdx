**Design proposal · Not released**

## Overview

The canonical Tabs component is not implemented yet. Site navigation uses links, not tabs.

## Usage guidance

Use short, distinct labels for related views of the same subject. Do not hide required steps inside panels. Use normal links for separate destinations.

## States and accessibility

| State | Requirement |
| --- | --- |
| Selected | Identify the active tab through more than colour alone. |
| Keyboard focus | Support arrow keys, Home, End and a documented activation model. |
| Narrow screens | Keep every label readable and reachable without widening the page. |

## Reference

Base UI will own tab semantics, keyboard behaviour and panel relationships. The public composition API and Markdown export remain pending.
